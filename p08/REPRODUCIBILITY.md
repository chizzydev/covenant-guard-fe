## Reproducible Fe release layout

- `fe.toml` + `src/lib.fe`: **root adoption ingot** that imports `covenant_transition` via local dependency (new in P08; compiler qualification pending).
- `library/covenant_transition/fe.toml` + `src/lib.fe`: the one reusable checked-transition library.
- `consumers/allocation_flagship`: authoritative 3-market allocation reference contract used by both browser surfaces.
- `consumers/governance_registry`: independent governance domain with different invariants and delay-based risk buffer.
- `consumers/allocation_pilot`: third miniature Fe consumer, not a competing source of allocation truth in the default application.
- `contracts/CovenantControl.fe`: preserved original legacy contract; not default cutover runtime.
- `probes/legacy_build_fixture`: build-only Fe ingot containing an **exact byte copy** of that legacy file. New root `fe.toml` affects standalone-file contract building; both Windows and Ubuntu build through this explicit fixture and verify byte identity. The original source still supplies the 34 legacy Fe tests. This fixture is not deployed by default.
- `app`: local Node + EthereumJS integration, seven-view workspace and Guard dashboard.
- `p07`: independent Python model and EVM differential/mutation tests.
- `p08`: portable test runner, judge witness, and provenance/receipt validators.

This is a *repository-root runnable ingot* plus multiple packages, not a single `fe build` that magically bundles every consumer. The acceptance scripts explicitly check/test/build the relevant ingots.

## Ubuntu 24.04 LTS

The user may use their existing Ubuntu VM rather than fresh hardware.

1. Extract the archive into a new directory (or clone a future branch).
2. Confirm Node >=20, npm, Python >=3.11 and `curl` are available.
3. If `fe --version` isn't `fe 26.5.0 (3dab95f)`, execute **only after reviewing** `bash scripts/INSTALL_FE_UBUNTU.sh`. Installer is fetched from the `v26.5.0` tag, **not a moving master branch**. It downloads Fe's release binary and records its local SHA-256. Network is needed to install it and npm dependencies.
4. Run `bash RUN_P08_UBUNTU.sh`. The command runs source checks, root ingot test, all 98 baseline Fe tests, compiler-negative controls, all Fe builds, 45 Node tests, independent oracle, 300/72/432 comparisons, eight compiled mutants, witness and generated receipts.
5. Retain `results/p08/P08_LINUX_RUN_LOG.txt`, `results/p07/P07_RUN_MANIFEST.json` and `results/p08/P08_REPRODUCIBILITY_RECEIPT.json`.

To enforce the Linux binary hash after the first trusted Ubuntu run, set `P08_LINUX_FE_SHA256=<observed validated digest>` and rerun the complete gate. P08-R3 **reports observed Linux SHA separately** rather than inventing a cross-platform binary digest. A release freeze requires approval of that Linux SHA and the real Ubuntu run.

## Six-action judge witness

From a prepared workspace with contract bytecode and `node_modules`, execute `node p08/judge-witness.mjs`. It creates a disposable local EVM and:

1. Guardian stores an incident exposure limit and reserve requirement.
2. Authorized operator partially improves the deficit vector.
3. Authorized operator tries to worsen exposure; Fe reverts without state change.
4. Authorized operator completes containment.
5. Reviewer tries to release an incident; Fe reverts without state change.
6. Guardian performs incident-ID-bound release.

Every action and complete final snapshot is checked against `p07/spec/oracle.py`. The script stores a fresh `results/p08/JUDGE_WITNESS.json`. Results are not hardcoded.

## Trust/security limitations

This is an **educational local prototype**, not a system for real deposits, production authorization or live settlement. Fe 26.x is itself not production-ready. The browser's role selector and local EVM keys are demonstration fixtures. Existing local JSONL evidence is hash-linked but not tamper-proof. The independent Python specification is bounded; mutation coverage is deliberate, not formal proof. Owner and ChatGPT handle documentation, demo and contest submission; Codex is reserved for an independent engineering review after reproducibility is established.
