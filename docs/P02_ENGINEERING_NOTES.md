## Implemented in this package

- New separate ingot `covenant_transition` with `Draft` (only `a,b,c` public), private permanent rules, private revision, and one checked Fe projection whose slide verifies the final state and commits exactly one version increment.
- Immediate ordered instruction semantics: 0–8 MOVE, 9–11 RETIRE, 12–14 ISSUE, 15–17 EXPECT, up to 3 operations; immediate source/free-budget checks never waived by the end-of-transaction invariant.
- Direct preview and commit; action preview and commit; exact-target action commit; multi-stage migration allowing temporarily unhealthy intermediate states; input ceilings; version binding.
- Separate allocation ingot consuming the library. Actual EVM caller authorization belongs in the consuming contract; unauthorized contract caller is denied.
- `EarlyReturnFixture` is separate from the published adapter: there is no `earlyInvalid` test backdoor in `AllocationKernel`.
